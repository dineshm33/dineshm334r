# Karthikeya M. — ECE Portfolio

A responsive, animated, single-file portfolio built with HTML, CSS and JavaScript. It works on GitHub Pages and includes a lightweight visual editor.

## Quick start on Android

1. Sign in at https://github.com/
2. Create a **public** repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
3. Open the repository → **Add file** → **Upload files**.
4. Upload `index.html` from this ZIP. Upload `assets/resume.pdf` too after adding your real resume.
5. Commit the changes.
6. Open **Settings → Pages**. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
7. After publishing, visit `https://YOUR-USERNAME.github.io`. The first build may take several minutes.

Official guide: https://docs.github.com/en/pages/quickstart

## Editing on your phone

- Open your published site and tap **Visual edit** in the bottom toolbar.
- Tap outlined text and edit it.
- Tap **Save draft** to keep a local draft in that browser on that device.
- Tap **Export HTML** to download the edited `index.html`.
- In GitHub, open your repository, select `index.html`, tap the pencil/edit icon, then use the file upload route instead if replacing the whole file is easier: **Add file → Upload files** and commit the new `index.html`.
- Changes on the public site only happen after you commit/upload the exported file to GitHub. The browser editor does not directly change the published website.

## Personalize before sharing

Search and replace:
- `Karthikeya M.` / `Karthikeya.` if you want another display name
- `your.email@example.com` with your email
- `https://www.linkedin.com/` with your profile URL
- `https://github.com/` with your GitHub profile/repository URLs
- Sample project links and certificate links with real URLs
- Put your real resume at `assets/resume.pdf`

Create an `assets` folder and upload your resume PDF there. If you have not added it yet, the resume button will not work.

## Important

- Do not publish phone numbers, home address, student IDs, or private information you don't want public.
- Describe projects accurately. If a project is still a concept, label it as a concept until it is implemented.
- GitHub Pages is static hosting; this site has no server/database or online multi-user CMS. The visual editor is for local edits and export. For code access, edit `index.html` directly.
