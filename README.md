✏️ How to Edit This Portfolio

1. Open the portfolio website.
2. Tap Visual edit to modify supported text directly.
3. Tap Save draft to save changes in your current browser.
4. Tap Export HTML to download the updated "index.html".
5. Upload the updated file to your GitHub repository.
6. Commit the changes to publish the updated portfolio.

You can also edit "index.html" directly to customize the HTML, CSS, animations, colors, and layout.

🚀 Deployment

This website is hosted using GitHub Pages.

1. Upload "index.html" to your repository.
2. Open Settings → Pages.
3. Select Deploy from a branch.
4. Choose the "main" branch and "/(root)" folder.
5. Save and wait for deployment.
